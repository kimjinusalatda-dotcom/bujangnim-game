# 부장님때리기 — GitHub Pages 배포 파일

## 파일 구성
- `index.html`: 웹사이트 화면 구조
- `style.css`: 디자인과 반응형 스타일
- `script.js`: 게임 동작

## GitHub에 올리는 방법
1. GitHub에 로그인하고 새 저장소(Repository)를 만듭니다.
2. 저장소 이름을 예: `bujangnim-game` 으로 정합니다.
3. `Add file` → `Upload files`를 누릅니다.
4. `index.html`, `style.css`, `script.js` 세 파일을 저장소 최상위에 업로드합니다.
5. `Settings` → `Pages`로 이동합니다.
6. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
7. Branch는 `main`, 폴더는 `/(root)`로 선택한 뒤 `Save`를 누릅니다.
8. 잠시 기다리면 Pages 화면에 웹사이트 주소가 표시됩니다.

## 확인 사항
- 파일 이름은 반드시 `index.html`, `style.css`, `script.js`로 유지하세요.
- 세 파일은 같은 폴더(저장소 최상위)에 있어야 합니다.
- 원본 코드에서 참조하는 외부 리소스는 인터넷 연결이 필요할 수 있습니다.
